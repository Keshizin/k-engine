# K-Engine File Formats

# K-Engine config json

## Projection information

```json
{
	"projection_info_": 
}
```

Campo ```projection_info_``` é um inteiro (```enum class```):


| Valor | Nome |
| ----- | ---- |
| 0     | _2D |
| 1     | _3D_ORTHO |
| 2     | _3D_FRUSTUM |
| 3     | _3D_PERSPECTIVE |
